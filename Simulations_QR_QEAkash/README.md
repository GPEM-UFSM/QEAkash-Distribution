# QR-QEAkash regression: Monte Carlo simulation

These scripts reproduce the simulation for quantile regression with the
Quantile Exponentiated Akash distribution, without censoring and with right
censoring. For `tau = 0.5`, both parameters follow logarithmic links,

```
log(mu_0.5,t) = beta11 + beta12 x_t1 + beta13 x_t2
log(sigma_t)  = beta21 + beta22 z_t1 + beta23 z_t2
```

Failure times are generated by inverse transform sampling, and the six
coefficients are estimated by maximum likelihood.

## Scenarios

| Scenario | Covariates in `log(mu)` | Covariates in `log(sigma)` | True `beta1` | True `beta2` | Target censoring |
|:--|:--|:--|:--|:--|--:|
| R1 | age, infection risk | North-Central, South | (1.47, 0.01, 0.05) | (-0.01, 0.31, 0.47) | 0% |
| R2_15 | age, log(bilirubin) | log(bilirubin), log(albumin) | (8.81, -0.01, -0.51) | (-4.48, 0.59, -2.41) | 15% |
| R2_30 | as R2_15 | as R2_15 | as R2_15 | as R2_15 | 30% |
| R2_60 | as R2_15 | as R2_15 | as R2_15 | as R2_15 | 60% |

R1 uses the covariates of the 113 hospitals of the SENIC study
([senic.txt](QR_QEAkash_Simulation_Functions/senic.txt), from Kutner et
al., *Applied Linear Statistical Models*, 5th ed., Appendix C1): average
patient age and infection risk in the quantile submodel, and indicators of
the North-Central and South regions in the `sigma` submodel. The R2
scenarios use the first 312 patients of `survival::pbc`, the Mayo Clinic
primary biliary cholangitis trial. In each replication, the covariates of
`n` units are drawn with replacement from these pools.

Censoring times follow `C ~ U(0, nu)`, independent of the failure times.
Since `P(C < T) = E[min(T, nu)]/nu`, `nu` is calibrated from 200,000
failure times generated with seed 7 so that the expected censoring
proportion matches the target: `nu = 27001.80`, `13028.68` and `5021.75`
days for 15%, 30% and 60%. The observed response is `y = min(T, C)` with
indicator `delta = 1(T <= C)`.

Each scenario crosses four sample sizes (50, 100, 200, 400), with 10,000
replications per configuration. The seed of replication `k` is
`90000 + 1000 id + n + 10 k`, with `id` = 1, 3, 4 and 2 for R1, R2_15,
R2_30 and R2_60. The three R2 scenarios therefore share covariates and
failure times in most replications and differ only in censoring.

| Scenario | Failures at n = 50 | 100 | 200 | 400 | Mean censoring |
|:--|--:|--:|--:|--:|--:|
| R1 | 0 | 0 | 0 | 0 | 0% |
| R2_15 | 5 | 0 | 0 | 0 | 15.0% |
| R2_30 | 27 | 0 | 0 | 0 | 30.0% |
| R2_60 | 430 | 1 | 0 | 0 | 60.0% |

With 60% censoring and `n = 50`, about 20 failures are observed per sample.
The likelihood then becomes flat in `sigma`, which is identified by the
right tail that censoring removes.

## Estimation

The log-likelihood is

```
l(theta) = sum_t delta_t log g(y_t; mu_t, sigma_t)
         + (1 - delta_t) log[1 - G(y_t; mu_t, sigma_t)],
```

which reduces to the usual log-likelihood when `delta_t = 1` for all `t`.
It is maximized with `nlminb()` and the closed-form score, with covariates
standardized internally. Starting values are least squares of `log(y)` for
`beta1` and a one-dimensional profile search for the intercept of
`log(sigma)`. Up to three Newton steps with the observed information
follow, and the maximum is accepted when the Newton decrement is below
`1e-6` and the observed information is positive definite. Otherwise the
replication counts as a failure. Standard errors come from the inverse
observed information. The summaries include mean, bias, MSE and empirical
coverage of 95% Wald intervals for the coefficients, computed over the
accepted replications.

## Scripts

| Script | Purpose |
|:--|:--|
| `01_FUNCOES_QR_QEAKASH.R` | Stable Akash distribution function, data generation, censored log-likelihood and score, estimation, calibration of `nu`, one replication, and `qr_qeakash_fit()` |
| `02_SIMULACAO_QR_QEAKASH.R` | Covariate pools, scenarios, seeded replications in parallel, checkpoints and run log |
| `03_TABELAS_GRAFICOS_QR_QEAKASH.R` | CSV summary, LaTeX tables, boxplots and standardized density plots |
| `senic.txt` | SENIC hospital data used as the covariate pool of R1 |

The scripts require `numDeriv` and `survival`, and the figures `ggplot2`.
Install them with `install.packages(c("numDeriv", "survival", "ggplot2"))`.
They were tested with R 4.5.3.

## Run from QR_QEAkash_Simulation_Functions

First run a small test with 40 replications of every scenario at
`n = 50`. Because the seeds depend only on the configuration and the
replication index, these replications reproduce the first 40 of the
archived run.

```sh
Rscript -e 'options(QRQEAKASH.mode="test", QRQEAKASH.n=50); source("02_SIMULACAO_QR_QEAKASH.R")'
Rscript 03_TABELAS_GRAFICOS_QR_QEAKASH.R RESULTADOS_MONTE_CARLO/test_qr_qeakash_R00040
```

Run the full design (R1, R2_15, R2_30 and R2_60) and generate its report:

```sh
Rscript 02_SIMULACAO_QR_QEAKASH.R
Rscript 03_TABELAS_GRAFICOS_QR_QEAKASH.R RESULTADOS_MONTE_CARLO/full_qr_qeakash_R10000
```

Use `QRQEAKASH.scenarios` to select scenarios, for example
`options(QRQEAKASH.scenarios = "R1")`. Set `QRQEAKASH.workers` to control
the number of parallel processes and `QRQEAKASH.output_root` to direct a
run to another directory. Rerun the same command to resume from
checkpoints. Without arguments, `03_TABELAS_GRAFICOS_QR_QEAKASH.R`
summarizes the archived run and writes to
`TABELAS_E_GRAFICOS/QR-QEAkash_Simulations/`.

## Fit a QR-QEAkash model with censoring

`qr_qeakash_fit(y, delta, X1, X2, tau)` fits the model by the same routine.
The design matrices include a column of ones for intercepts.

```r
source("01_FUNCOES_QR_QEAKASH.R")
pbc <- survival::pbc[1:312, ]
y <- pbc$time
delta <- as.integer(pbc$status == 2)        # deaths; others are censored
X1 <- cbind(intercept = 1, age = pbc$age, log_bili = log(pbc$bili))
X2 <- cbind(intercept = 1, log_bili = log(pbc$bili),
            log_albumin = log(pbc$albumin))
fit <- qr_qeakash_fit(y, delta, X1, X2, tau = 0.5)
cbind(estimate = fit$coefficients, se = fit$se)
fit$loglik
```

The function returns `NULL` when the fit fails. Otherwise it returns the
coefficients, standard errors, covariance matrix and maximized
log-likelihood.

## Archived results

The [archive](QR-QEAkash_Simulations/) contains one `.rds` file per
configuration, named `<scenario>_tau_05_n_<n>.rds`. Each file is a list
with `configuration` (scenario, `tau`, `n`, target censoring), `truth`
(the six coefficients), `censoring_nu`, `replications`, `failures`,
`seeds` and `estimates`. The data frame `estimates` has one row per
accepted replication, with the replication index and seed, the six
estimates, the coverage indicators `covered_beta11`, ...,
`covered_beta23`, and the censoring proportion of the sample.

```r
r2 <- readRDS("QR-QEAkash_Simulations/R2_60_tau_05_n_100.rds")
r2$failures
colMeans(r2$estimates[c("beta11", "beta21", "censoring")])
```
